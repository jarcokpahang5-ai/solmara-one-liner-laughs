# One-Liner Laughs — The Fridge Is a Witness

A single original one-liner for the make.fun "One-Liner Laughs" bounty: a smart fridge that has seen one too many midnight snack raids and finally files a complaint.

`main.py` (pure Python 3 standard library, fully self-contained) writes the line plus a trailing newline to `/output/entry.txt` and prints exactly the line to stdout.
